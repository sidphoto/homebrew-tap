# sidphoto/homebrew-tap

Homebrew casks for [VBear](https://github.com/sidphoto/vbear).

```sh
brew install --cask sidphoto/tap/vbear
```

VBear is not signed with an Apple Developer ID yet. The first time you open it, macOS will refuse; open
**System Settings → Privacy & Security** and click **Open Anyway** next to VBear.

`brew uninstall --zap vbear` also removes VBear's state directory (`~/.vbear`).
